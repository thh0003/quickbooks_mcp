Disconnected from QuickBooks

QuickBooks Time & Invoice Connector, operated by PGE Software.

The connector's access to your QuickBooks Online company has been revoked by Intuit. It can no longer read or write anything in that company.

Finish cleaning up on your computer

The now-invalid tokens are still in the connector's token file. Delete it to remove them:

rm ~/.qbo_mcp/tokens-production.json (or tokens-sandbox.json for a sandbox company, or the path set in QBO_TOKEN_PATH).

Reconnecting later

Run uv run qbo-mcp authorize again and approve access in QuickBooks. Time entries and invoices already created remain in QuickBooks; disconnecting does not delete them.
